# 🎲 도박 RPG

폰과 PC 브라우저에서 바로 하는 마법세계 실시간 액션 RPG.

## 특징
- **종족 4개**: 인간 · 엘프 · 드워프 · 마족
- **직업 4개 + 2차 전직(Lv20)**: 마법사→흑마법사/백마법사 · 검사→소드 익스퍼트/절정의 경지 · 궁수→마법궁수/전통궁수 · 레인저→저격수/돌격대장
- 스킬: 기본 5개(Lv1·4·7·9·11 습득) + 스킬북 3개 + 공용 4개 + 전직 2개, 슬롯 3칸에 골라 장착
- 맵: 평화의 마을 → 바람의 들판 → 모르간의 던전(보스) → 저주받은 폐허(Lv12+)
- ❄ 설산마을(Lv130+): 모르간의 던전 보스방 오른쪽 숨겨진 공간의 동아줄 → 설산마을 → 설원(예티의 발자국) → 예티의 얼음 동굴(Lv160 보스)
- 마법 도서관(스킬북), 상점, 여관, 전직의 전당, 🎲 도박장(동전·상자·강화)
- 대쉬(Shift / 💨): 짧은 무적 회피
- **계정 로그인·서버 저장·실시간 접속**: RANDOM FOOTBALL 서버의 `/rpg/` 로 접속하면 같은 계정으로 로그인해 서버에 저장되고, 같은 맵의 다른 플레이어가 보여요. (GitHub Pages 주소에서는 기기 저장만)

## 조작
- PC: WASD/방향키 이동 · Space/마우스 클릭 공격 · 1~3 스킬(마우스 방향) · Shift 대쉬 · E 대화 · Z/X 물약 · M 메뉴
- 폰: 왼쪽 화면 드래그로 이동 · 스킬 버튼을 누른 뒤 화면을 터치하면 그곳으로 발사 (버튼을 두 번 누르면 자동 조준)

## 실행
`index.html` 한 파일로 돌아가요. GitHub Pages를 켜면 링크로 바로 플레이할 수 있어요.

## 배포

`main`에는 원본 코드를 두고, 게임 사이트(`gh-pages`)에는 난독화된 배포본을 올린다.
`main`에 커밋·푸시한 뒤 `bash tools/deploy.sh`로 배포한다. `gh-pages`에 원본을 직접 푸시하지 않는다.
