# 🎲 도박 RPG

폰과 PC 브라우저에서 바로 하는 마법세계 실시간 액션 RPG.

## 특징
- **종족 4개**: 인간 · 엘프 · 드워프 · 마족
- **직업 4개**: 마법사(원소 마법) · 검사(근접·돌진) · 궁수(활 + 활 마법) · 레인저(총 + 덫)
- 스킬 12개/직업: 기본 4개(레벨로 습득) + 스킬북 4개 + 공용 4개, 슬롯 6칸에 골라 장착, 스킬 포인트로 Lv5까지 강화
- 마법 도서관(스킬북 상점), 여관, 대장간이 있는 큰 마을
- 대쉬(Shift / 💨 버튼): 짧은 무적 회피
- 맵: 평화의 마을 → 바람의 들판 → 모르간의 던전 (보스: 리치 모르간)
- 촌장 퀘스트 5개 (1장 스토리)
- 상점: 무기·방어구·장신구·물약 구매/판매
- 🎲 도박장: 동전 던지기, 랜덤 장비 상자(전설 1%), 장비 강화(+10까지)
- 자동 저장 (브라우저 저장소)

## 조작
- PC: WASD/방향키 이동 · Space/마우스 클릭 공격 · 1~6 스킬 · Shift 대쉬 · E 대화 · Z/X 물약 · M 메뉴
- 폰: 왼쪽 화면 드래그로 이동 · 오른쪽 버튼으로 공격/스킬 (가까운 적 자동 조준)
